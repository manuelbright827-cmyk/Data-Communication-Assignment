02 / Core Topics

What I Have Studied

Data Communication explains how data is represented, transmitted, protected, and delivered reliably between systems.

TEL

Telegraph

The electric telegraph shows how coded messages were transmitted through electrical signals over long distances.

MOR

Morse Code

Morse code represents letters and numbers using short and long signal pulses known as dots and dashes.

SIG

Data Signals

Data signals explain how information is carried in analogue or digital form through communication channels.

OSI

OSI Model

The OSI model divides network communication into seven layers, from the physical layer to the application layer.

PGP

PGP

Pretty Good Privacy protects messages and files through encryption, digital signatures, and key management.

CPT

Cisco Packet Tracer

Cisco Packet Tracer is used to design, simulate, and test computer networks before real deployment.

CIA

CIA Triad

The CIA triad covers confidentiality, integrity, and availability as the main goals of information security.

SAT

Satellites

Satellite communication uses orbiting systems to send voice, data, television, and internet signals across wide areas.

NET

Networking

Networking connects computers and devices so they can share data, services, and resources efficiently.

AP

Access Point

An access point allows wireless devices to connect to a wired network using Wi-Fi technology.

POE

Power over Ethernet

Power over Ethernet carries electrical power and network data through the same Ethernet cable.

DC

Data Communication

Data Communication is the process of sending and receiving digital information between devices through a medium.

KLE

Kleopatra Encryption

Kleopatra is a certificate manager used with OpenPGP tools to encrypt, decrypt, sign, and verify files or messages.

03 / Historical Roots

The Electric Telegraph

The telegraph is an early example of data communication because it transmitted coded information electrically over long distances.

Fig. 1 - Simplified telegraph system showing signal movement from sender to receiver.

How It Worked

01

The sender pressed a Morse key to create short and long electrical pulses.

02

The wire carried the pulses across distance through a connected circuit.

03

The receiver converted the pulses into audible clicks or marks.

04

The impact proved that information could be coded and transmitted electronically.
